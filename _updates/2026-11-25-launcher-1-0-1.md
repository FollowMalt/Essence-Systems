project: essence

The Essence Launcher is on 1.0.1, and it has two final tests left before it comes to this site. The launcher now handles updates itself: it swaps in the new version, starts it and checks it opened properly. If the new version doesn't start within 2 minutes, it puts the old one back. It also recovers from updates that were cut off, say if the PC shut down. Every update is still checked against Essence's signature, size and fingerprint, your library is backed up first, and the previous version is kept so going back doesn't need a download.
